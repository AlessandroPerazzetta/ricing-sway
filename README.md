# Ricing SWAY WM

#### Config files for:

- `sway`
- `waybar`
- `foot`
- `alacritty`
- `htop`


### Installation

- Clone this repository -
```
$ git clone --depth=1 https://github.com/AlessandroPerazzetta/ricing-sway.git
```

- Change to cloned directory and make setup.sh executable -
```
$ cd ricing-sway
$ chmod +x setup.sh
```

- Run `setup.sh` -
```
$ ./setup.sh
